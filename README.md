## 🚀 Desplegar en Vercel (30 segundos)

### Opción A — Arrastrar carpeta
1. Ve a https://vercel.com/new
2. Arrastra esta carpeta completa
3. Clic en Deploy → URL lista ✅

### Opción B — Con GitHub
1. Crea repo en GitHub → sube los 3 archivos
2. Conecta en Vercel → Deploy ✅
3. Cada push = redeploy automático

## 🏠 Agregar propiedades en Supabase

Ve a https://trbamfvvpdmmdxpjiiqx.supabase.co
→ Table Editor → propiedades → Insert row

Campos disponibles:
- titulo, precio, ciudad, descripcion
- imagen (URL), area, habitaciones, banos, tipo
- estrato, parqueadero, antiguedad, piso
- permuta (boolean), caracteristicas (JSON array), activo (boolean)

Ejemplo caracteristicas: ["🚗 Garaje","🏊 Piscina","🔐 Conjunto cerrado"]
